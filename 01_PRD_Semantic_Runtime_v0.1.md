# Semantic Runtime PRD v0.1

## Positioning

Semantic Runtime is an open-source semantic infrastructure layer for AI
Agents.

It does not replace: - LLMs - Agent frameworks - Databases - MCP

It provides: - semantic understanding - context resolution - evidence -
safe execution

Core idea:

Models provide intelligence. Tools provide capability. Semantic Runtime
provides understanding.

## Problem

Current AI Agents can call tools but do not understand business worlds.

Main problems:

1.  Understanding

-   What entities exist?
-   What do concepts mean?

2.  Reasoning

-   How are objects related?

3.  Safety

-   Can an agent safely operate on data?

## Vision

Become the semantic layer between AI Agents and complex real-world
systems.

## Core Objects

-   Entity
-   Relation
-   Metric
-   Evidence
-   Policy

## Scope Boundaries

Not building: - Agent framework - BI platform - RAG framework - Workflow
engine - Database
